# components/product

Product-domain components.

- `ProductCard` — **Implemented.** Supports optional `sizes` (Men/Women
  listing cards) and `discountPct` (shown next to compare-at price when
  set) on top of the base Home variant.
- `CategoryCard` — **Implemented.**
- `RatingStars` — **Implemented.**
- `FilterPanel` — **Implemented** (introduced for Men): the "FILTERS"
  button + category-checkbox dropdown shared by listing pages.
- `SortSelect` — **Implemented** (introduced for Men): the 4-option sort
  dropdown shared by listing pages.
- `SizeSelector`, `ColorSwatches`, `QuantityStepper` — not yet needed;
  these belong to Product Detail, not yet built.
